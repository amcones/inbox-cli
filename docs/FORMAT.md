# 存储格式 v1

目录为 `YYYY/MM/YYYY-MM-DD.md`，年份限定四位。读取只发现符合该路径约定的普通文件，不遍历符号链接及任意位置的 Markdown。`.inbox/format-version` 为 UTF-8 `1\n`。

```markdown
# 2026-09-29

<!-- inbox:note {"id":"a83f912b-3a76-4aa0-9e31-61afc2b3e420","created":"2026-09-29T09:42:18+08:00","tags":["产品","博客"]} -->
- 09:42:18 为博客增加阅读模式
  支持调整字号和行距。
<!-- inbox:end a83f912b-3a76-4aa0-9e31-61afc2b3e420 -->

```

每条记录由一个根级元数据注释、一个 Markdown 列表项和一个根级结束注释组成。渲染 Markdown 时可见时间和正文；标签保存在注释内，CLI 列表和 show 会显示标签。

- 元数据使用 JSON，字段为 `id`、`created`、`tags`，v1 拒绝未知字段。
- ID 为小写带连字符 UUID；程序生成 UUID v4。
- `created` 是 `YYYY-MM-DDTHH:MM:SS[.小数秒]±HH:MM`，日期必须匹配文件名。程序写入 9 位小数秒；读取也接受无小数秒或 1–9 位小数秒，保证同一秒内连续记录仍可按实际时间排序。
- 元数据中的 `<`、`>`、`&` 用 JSON Unicode 转义，防止标签提前闭合 HTML 注释。
- 正文首行前缀是 `- HH:MM:SS `；每个续行缩进两个空格，包括原始空行。
- 正文首尾空白和末尾换行保留。编辑器去掉空行上的两个空格时，读取仍接受该空行。
- 结束注释的 ID 必须与开始注释一致，结尾为换行，条目之间空一行。
- 正文里的保留标记因列表前缀/缩进不会被误认为根级分隔符。
- 首版只验证应用自有格式，不解析任意 Markdown 结构。

应用新增时只检查文件尾部的完整结束标记，不检查所有历史记录。内部已损坏但尾部完整的文件，可能仍可追加；全量检查由 `doctor` 完成。正文或元数据的任意字节损坏不保证可检测，本格式没有内容校验和。

`.inbox/views.log` 为 UTF-8 TSV，每次有效浏览追加一行：

```text
a83f912b-3a76-4aa0-9e31-61afc2b3e420<TAB>2026-09-29T02:00:00Z<LF>
```

每行包含完整 ID 和浏览时间。时间使用 RFC 3339，可以有小数秒。以同一 ID 的行数作为浏览次数。丢失完整日志会丢失全部浏览历史；首版不进行日志压缩。

写入失败可能留下无结束标记的 Markdown 条目或无换行的日志行，后续操作会报错并保留原字节。文件锁只协调 inbox 进程；外部写入需要用户保证互斥。读取列表只验证实际扫描到的文件；检查全部数据请运行 `doctor`。

## 删除恢复与回收站

记录格式版本仍为 1。删除临时目录 `.inbox/delete-pending/` 包含一个或多个 `day-YYYY-MM-DD.next`、`views.next`、每条记录对应的 `trash-<UUID>.json.next`，以及包含 `dates`、完整 `ids` 数组和 `trash` 标记的 `manifest.json`。读取时仍兼容 v0.2 的 `day.next` 及单个 `date`/`id` 清单；旧事务不会凭空生成回收站内容。

先同步全部暂存文件和 `manifest.tmp`，再将其改名为 `manifest.json` 并同步目录，以此提交整批删除意图。恢复时先将回收站副本移入 `.inbox/trash/<UUID>.json`，再原子替换日期文件与浏览日志，验证记录已离开活动数据且回收站副本有效，最后清除恢复目录。

每次打开库都会在锁内检查已提交的清单；若存在则持独占锁继续替换，成功后才能执行用户命令。没有清单的暂存内容不影响原始数据，可由下次删除清理。恢复过程可重复执行，已改名的暂存文件无需再次应用。批量确认在事务暂存前完成，清单仅包含确认时的 ID 快照。创建回收站后，不要再用不理解回收站协议的旧版本操作同一个库。

回收站文件为 UTF-8 JSON，包含格式版本 `version: 1`、RFC 3339 `deleted_at`，以及原始 `meta` 和 `content`。恢复会把原记录追加回其创建日期对应的 Markdown 文件，并删除回收站 JSON；浏览日志不会恢复。`doctor` 会验证每个回收站文件的文件名、版本、时间、元数据和正文。
